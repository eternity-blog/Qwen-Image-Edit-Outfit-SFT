# 任务背景

电商营销视频关键帧需要**局部换装**：保留源帧人物姿势、构图与背景，将服装替换为目标商品，再交给视频模型做段间运动。

现网常用 GPT Image 2 + 长编辑指令。本仓库用 **Qwen-Image-Edit-2511** 在同一设定下做数据构建、SFT（LoRA / 全参 ZeRO-3）与评测。

### 数据字段

```text
edit_image[0] = 源关键帧
edit_image[1] = 商品参考
prompt        = 长编辑指令（全文 v2）
image         = 监督目标（合成 GT）
```

模型与训练原理见 [KNOWLEDGE.md](KNOWLEDGE.md)。

---

## 为什么用 IDM-VTON 造数据，而不是直接用它换装

IDM-VTON 是**单任务专用** try-on 网络，与线上需求不是同一个任务。

**1. 依赖链。** IDM-VTON 的输入除人物图与平铺服装图外，还需要 human parsing、densepose、
agnostic mask、openpose 等前置产物。VITON-HD 里这些是数据集预先算好的；真实视频帧上要现算
四个前置模型，任一环节失败整条链就失败，级联失败率与延迟在生产里不可接受。
Qwen-Image-Edit 是端到端指令编辑，输入只有图与文字。

**2. 任务范围。** 线上一条 v2 指令同时要求：换装、保留构图/姿态/遮挡/光线、处理商品爆点文案与
底部字幕、融合最多 3 张不同视角的商品参考图。IDM-VTON 接不了文字指令，也做不了后面这些。

**3. 域限制。** IDM-VTON 训练域为正面站姿、干净背景、上半身平铺衣服；真实关键帧是运动姿态、
复杂背景、遮挡、非正面，直接套用会崩。

**4. 可控性。** 业务规则是自然语言表达的（「只允许替换目标服装」「保留品牌 Logo」
「背面未知时不要臆造」）。只有指令式模型能承载这类约束，专用网络没有这个入口。

所以本项目是标准的**专家模型 → 通用骨干**蒸馏：用专用模型在其擅长域内廉价批量生成
(输入, 目标) 对，把换装先验注入一个能接自然语言、能多图条件、能端到端部署的通用编辑模型。

**已知边界（不隐藏）：** teacher 的质量即学生的上限；且实测表明仅用 VITON 域 + 单一 prompt
蒸馏，在真实关键帧上尚不可用（见 [DATA_SCALING_PLAN.md](DATA_SCALING_PLAN.md) 第 2 节诊断）。

**至于为何不直接用 GPT Image 2 出图**：外部付费 API 的成本与延迟不可控、有限流、权重不可控
因而无法针对业务微调、且数据需出域。自研骨干的动机在此。
